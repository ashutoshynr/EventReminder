# Event Reminder (Android)

Open in Android Studio (Koala / Ladybug or newer): File > Open > select this folder, let Gradle sync, press Run.
Requires JDK 17 (bundled with Android Studio). minSdk 26 (Android 8.0), targetSdk 34.

Features: Room database (events.db) | Birthdays / Anniversaries / Festivals / Others | per-category colours and alarm sounds |
daily alarm starting N days before the event with snooze | paged list sorted by date | email backup (CSV + .db) | reboot-safe alarms.
